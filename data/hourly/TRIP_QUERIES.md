# Phase 2c — exact SoQL queries used

Pulled 2026-11-15 by `trip_demand_ingest.py` / `trip_pull_one.py` / `trip_pull_remaining.py`. Server-side aggregation only; no raw rows downloaded. Each output row is a real count(*) of trips for one (day, hour, pickup community area) — never an average.

## Query template (one per dataset-range)

```
GET https://data.cityofchicago.org/resource/<DATASET>.json
$select=date_trunc_ymd(trip_start_timestamp) as day, date_extract_hh(trip_start_timestamp) as hour, pickup_community_area as area, count(*) as trips
$where=trip_start_timestamp >= '<start>' AND trip_start_timestamp < '<end>'
$group=day, hour, area
$order=day, hour, area
$limit=50000 (+ $offset=50000, 100000, ... until a short page)
```

Ranges: monthly by default; TNP months split into halves (1st–15th / 16th–end) and stubborn ranges into 7-day weeks, each a single page with no $offset (the $offset=50000 page proved unreliable, and the egress proxy drops long-lived connections — the last gap was pulled one chunk per fresh process). Socrata quirks found live: `$group` (not `$group_by`); `date_extract_hh()` for the hour (no `datepart()` or `date_trunc_hour()` on this portal); `date_trunc_ymd()` for the day.
